Dual-engine consensus docking framework

A reviewer asked for stronger confidence in the Als3 binding-pose predictions. Rather than re-running the same engine harder, I built a PharmaCoNet + AutoDock Vina consensus pipeline with Python-based RMSD validation, so a pose only survives if two independent scoring philosophies agree on it.

Consensus dockingRMSD validation PythonCADD
The problem
A single docking engine's top pose is a hypothesis, not a result. Agreement between engines is weak evidence; agreement plus low RMSD is considerably stronger.
What I built
A Python pipeline that docks with both engines, aligns the resulting poses, computes pairwise RMSD, and retains only poses converging below a set threshold.
Why it matters
It converts a reviewer objection into a reusable method. The same framework now applies to any target in the group, not only Als3.

Antifungal and antibiofilm library screening against Als3

Large-scale structure-based screening of a curated antifungal/antibiofilm library against Als3 (PDB 4LEB), with scaffold classification by ClassyFire and Murcko decomposition in RDKit. Residue-interaction analysis across 228 diagrams revealed a weak score–activity correlation — which is the interesting result, not a failed one.

Molecular dockingAls3 DFT / HOMO–LUMORDKit ClassyFire
Approach
Dock the curated library, classify every hit by chemical scaffold, then read the residue-level interaction pattern rather than trusting the score alone.
Finding
Docking score tracked reported activity only weakly, pointing to mechanistic heterogeneity: the library is not acting through one shared binding mode.
Limitation
Rigid-receptor docking cannot capture Als3 conformational change, and the activity data are aggregated across assay types. Both bound how far the correlation can be pushed.
2023 published

Natural carotenoid screening against Als3

The first published study to screen natural carotenoids against Als3, identifying mangicrocin as the top hit. This became the entry point for everything after it — the library work and the consensus framework both grew out of questions this study raised.

Natural productsVirtual screening Als3
Rationale
Carotenoids are long, flexible, amphipathic molecules — an unusual fit for the extended peptide-binding groove of an adhesin, and largely unexplored against this target.
Outcome
Mangicrocin emerged as the leading candidate, giving a concrete starting scaffold instead of a general claim about the class.
What it opened
It raised the question of whether score alone can rank such flexible ligands, which is precisely what the next two projects went on to test.
